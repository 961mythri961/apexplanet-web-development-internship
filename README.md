# ApexPlanet Web Development Internship Project

## Project Description
This project is a responsive website developed using HTML, CSS, and JavaScript. It demonstrates basic web development concepts, responsive design, and interactive website features.

## Features
- Responsive and user-friendly design
- Home section
- About section
- Projects section
- Contact section
- Mobile-friendly navigation menu
- Contact form validation using JavaScript

## Technologies Used
- **HTML5** – Website structure
- **CSS3** – Styling and responsive layout
- **JavaScript** – Interactive functionality
- **GitHub** – Source code hosting
- **GitHub Pages** – Website deployment

## Project Structure


## How to Run the Project
1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` to open the website in your browser.

## Deployment
This project can be hosted using GitHub Pages.

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and the `/ (root)` folder.
5. Click **Save**.
6. Open the published website using the URL displayed in the Pages settings.

## Testing
- Verify that all website sections display correctly.
- Check navigation on desktop and mobile screens.
- Test the contact form's validation messages.
- Confirm that CSS styling and JavaScript functionality work correctly.
